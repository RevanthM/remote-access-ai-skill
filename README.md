# Remote Access AI Skill

A reusable instruction set for AI agents to safely discover, configure, and troubleshoot remote computer access across Windows, macOS, and Linux using SSH and RDP.

## What it teaches

- Inventory hostname, IP, OS, CPU, RAM, GPU, and GPU VRAM
- Configure SSH clients and SSH servers
- Use Ed25519 public-key authentication
- Create friendly SSH aliases
- Configure Windows OpenSSH Server
- Configure macOS Remote Login
- Configure Linux OpenSSH Server
- Configure and test RDP when GUI access is required
- Troubleshoot permissions, usernames, ports, firewalls, and connectivity
- Avoid committing private keys, passwords, tokens, or other secrets

## Install/use

Point your coding agent at:

`skills/remote-computer-access/SKILL.md`

The agent should read that file before performing remote-access work.
